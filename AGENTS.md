## Project Overview

**OptiRefine** = use **Mixin 0.8.7** to rewrite OptiFine's bytecode patches for Minecraft **1.12.2** onto **Cleanroom** (= Forge environment). Goal: OptiFine features working under Cleanroom.

- 125 mixin classes registered: `optirefine.default.mixin.json` = 30 `mixins` + 95 `client` (`server` empty); `optirefine.mods.mixin.json` exists but its `mixins` list is empty
- OF's own bytecode transformer is disabled at runtime — **mixins are the only behavior source**
- Runtime baseline is the Cleanroom patched environment (`patch/forge`, SRG names), not the OptiFine jar
- Core principle: a mixin implements only the **delta OptiFine adds over Cleanroom**; already-landed Cleanroom/Forge hooks must not be duplicated
- Status (2026-08-07): non-shader rendering OK; **shader black triangles unsolved**; dynamic lights / putBulkData shader hooks wired, pending real-machine verification; `gradlew build` green; push authorized (origin/dev = 6fb0748)

## Architecture & Data Flow

```
Minecraft startup → OptiRefineCore (@IFMLLoadingPlugin, SortingIndex 1000,
                     TransformerExclusions mods.Hileb.optirefine.core.+library.)
  ├─ static setupTransformers() → TransformerHelper.registerTransformer(...)
  │   ├─ OptifineTransformerTransformer (prod): targets optifine.OptiFineClassTransformer —
  │   │   fixes URL.toURI→url2uri, renames transform→transform0, injects a wrapper whose
  │   │   couldNotTransform() ALWAYS returns true (OF transformer fully disabled)
  │   └─ OptiRefineConfigTransformer (prod): rewrites stub mods.Hileb.../Config references
  │       to root Config; runs on GameSettingsOptionOF and on every default-mixin target (postApply)
  │   └─ dev/ (deobf env only): OptifineDevUtilTransformer + OptifineDevTweakerTransformer
  ├─ getModContainerClass → OptiRefineCore$Container (DummyModContainer; /mcmod.info via MetaDataDecoder)
  ├─ IMixinConfigPlugin → DefaultMixinPlugin + ModMixinPlugin (per-mod gating via Loader.isModLoaded)
  └─ mixin postApply → CursedMixinExtensions.postApply(ClassNode)
       ├─ @Public / @AccessTransformer: visibility changes (deobf=true → SRG/MCP dual match)
       ├─ @AccessibleOperation: native stub → real bytecode (GET/PUT/INVOKE/NEW/INSTANCEOF/NOP)
       ├─ constructor extensions (@NewConstructor / @ReplaceConstructor / @ShadowSuperConstructor /
       │   @ShadowSuper / @ShadowConstructor)
       └─ @ChangeSuperClass / @SignatureFix / @Implements
       (12 annotation classes exist; @Stub is declared but NOT processed — dead)
```

Build pipeline: source compiles against MCP names → unimined `remapJar` (shadow disabled) → final jar with SRG names + refmap (`optifine.refmap.json`, shared by both mixin configs). Devrun (`runClient`) uses MCP names end to end.

## Code Conventions & Common Patterns

- **Injection prefix** `optiRefine$` (e.g. `optiRefine$initFields`, `optiRefine$renderWorldPass`); accessor fields `acc_` / `acc$` (e.g. `acc_rawIntBuffer`, `acc$fogColorRed`); `@AccessibleOperation` bridge names `_acc_<Class>_<member>_` or `BufferBuilder_xxx`
- **OF-added members** (no tsrg entry): `@Unique private` + `@Public`, plus `@SuppressWarnings({"unused", "AddedMixinMembersNamePattern"})` (sometimes `"MissingUnique"`). Declare fields **without initializer** — cleanmix does not inject `@Unique` field initializers; initialize via `@Inject(method = "<init>*", at = @At("RETURN"))`
- **Cross-injector state**: `@Share(namespace = "optirefine")` (LocalRef/IntRef/FloatRef/BooleanRef)
- **desc rules (`@AccessibleOperation`/`@AccessTransformer`)**: vanilla members → **SRG name + `deobf=true`** (prod runtime uses the raw name directly; only MCP runtime remaps); OF-added members → **MCP name**. `isSrgRuntime` detects `field_`/`func_` members on the target class
- **Mixin 0.8.7 hard rules** (every one has crashed in production):
  - static members (incl. `static final`) must be `private static` + `@Public` → else "non-private static field"
  - `@Shadow` only for members **declared by the target class itself** (interface/inherited → apply crash)
  - non-void injections → `CallbackInfoReturnable<T>`; static target methods → `private static` handler
  - `@At("NEW")` doesn't support arrays → `@ModifyConstant(intValue, ordinal)`
  - `@Unique public` with the same name as a target member is **silently dropped**
  - `@Shadow` + `@Unique` on the same method → apply crash (dangling annotations stick to next member)
  - `@At("INVOKE")` is BEFORE by default → `shift = At.Shift.AFTER` when needed
  - overloaded target methods need the full signature (else "ambiguous ... use FLAG_FIRST")
  - `@At("FIELD")` owner must be the **declaring class** (inherited field + subclass owner not found)
  - FML AT `<init>` entries don't work in Cleanroom → use cursed `@AccessTransformer`
  - `@NewConstructor` skips target-field init and `<init>*` injections → add manually
  - after vanilla `growBuffer`, `rawFloatBuffer` is read-only → restore `asFloatBuffer()` at TAIL
  - runtime ctor arity follows the JVM (non-static inner classes carry `this$0`)
- **Three-way workflow**: `patch/cleanroom` has the change (or `cleanroom_patch_summary.txt` says ADDED) → skip; else `diff -u patch/deobf/.../Foo.java patch/optifine/.../Foo.java` = the delta the mixin must implement. OF-added member = present in `patch/optifine`, absent in `patch/deobf` → supply via `@Unique`/`@Public` using the OF MCP name
- **Line endings CRLF**; Python file writes need `newline=''` and `\r\n` in patterns; run `wc -l` after bulk edits (17-line truncation incident)

## Testing & QA

**Zero automated tests**: no `src/test/`, no `*Test*.java`. JUnit5 (junit-jupiter 6.0.3, `enable_junit_testing=true`) is wired in build.gradle but empty-runs. QA is two-track:

1. **Static scans** (gitignored `.alma/`, run from repo root):
   - `python .alma/scan_review.py` → expect `NO PROBLEMS FOUND` (@Shadow/injection targets vs `patch/deobf`, `@Unique` collisions with Mixin 0.8 silent-drop semantics, NEW+Construction pairing)
   - `python .alma/scan_accessible_ops.py` → `NO ACCESSIBLE-OPERATION PROBLEMS` (opcode/desc shape, MIXED-SEPARATORS)
   - `python .alma/scan_wrapmethod_arity.py` → `NO ARITY ISSUES` (handler arity vs Forge baseline: target params + 1 Operation)
   - `python .alma/check_registered.py` → `ALL REGISTERED` + `registered total: 125`
   - `python .alma/validate.py` → `ALL CLEAN`; auxiliary: `check_json.py`, `check_blackboard.py`, `scan_mixins.py`, `audit.py`
   - `python .alma/deobf.py` — **WRITES** `patch/deobf` (regenerates baseline; not a pure scan)
2. **Real-machine crash loop** (primary): user runs HMCL `cleanroom-0.6.7-alpha` (+ `preview_OptiFine_1.12.2_HD_U_G6_pre1.jar`), ships `logs\latest.log` / `crash-reports\crash-*.txt`; loop = fix → build → commit → copy jar (verify `jar tf`) → retest. Log grep: `FATAL|Mixin apply|InvalidInjection|NoSuchField|NoSuchMethod|IllegalAccess`

Behavior baseline: `diff -u patch/deobf/... patch/optifine/...`.

**Known unresolved** (priority order): shader black triangles (blocks + items); `getRenderQuads` face passed null; `AmbientOcclusionFace.updateVertexBrightness` uses vanilla version (OF `fixAoLightValue` not ported); `MixinModelBakery` loadModel missing `models/` prefix; `CustomColors.getDurabilityColor` TODO; `MixinWorldEntitySpawner.findChunksForSpawning` OF logic commented out; Kirino headless 4-segment `renderWorldPass` not reimplemented; emissive re-render dead code after Cleanroom renderQuad replacement; `optiRefine$actionPerformedRightClick` unwired.
